# 📊 Data Structures & Algorithms Visualizer

An interactive web-based Data Structures and Algorithms (DSA) Visualizer built using **HTML, CSS, and JavaScript**. This project helps students and developers understand fundamental DSA concepts through real-time visual demonstrations and animations.

---

## 🚀 Features

### 📚 Data Structures

#### Stack (LIFO)

* Push Operation
* Pop Operation
* Peek Operation
* Stack Visualization
* Time Complexity Analysis

#### Queue (FIFO)

* Enqueue Operation
* Dequeue Operation
* Front and Rear Elements
* Queue Visualization

#### Linked List

* Insert Node
* Delete Node
* Search Node
* Traverse List
* Singly Linked List Visualization

#### Dynamic Array

* Dynamic Memory Allocation Simulation
* Automatic Array Resizing
* Capacity and Size Tracking

#### Binary Tree

* Tree Creation
* Node Insertion
* Tree Traversal Visualization

#### Graph

* Graph Representation
* Breadth First Search (BFS)
* Depth First Search (DFS)

---

## 🔍 Searching Algorithms

### Binary Search

* Sorted Array Search
* Midpoint Visualization
* Step-by-Step Execution
* Time Complexity: O(log n)

### Linear Search

* Sequential Search Visualization
* Time Complexity: O(n)

---

## 🔄 Sorting Algorithms

### Bubble Sort

* Adjacent Element Comparison
* Swap Animation
* Time Complexity: O(n²)

### Insertion Sort

* Element Insertion Process
* Step-by-Step Visualization
* Best Case: O(n)

### Selection Sort

* Minimum Element Selection
* Swapping Visualization
* Time Complexity: O(n²)

### Merge Sort

* Divide and Conquer Strategy
* Recursive Splitting
* Merge Process Visualization
* Time Complexity: O(n log n)

### Quick Sort

* Pivot Selection
* Partitioning Visualization
* Average Time Complexity: O(n log n)

---

## 📈 Complexity Analysis

The project demonstrates:

| Operation      | Best Case  | Average Case | Worst Case |
| -------------- | ---------- | ------------ | ---------- |
| Linear Search  | O(1)       | O(n)         | O(n)       |
| Binary Search  | O(1)       | O(log n)     | O(log n)   |
| Bubble Sort    | O(n)       | O(n²)        | O(n²)      |
| Insertion Sort | O(n)       | O(n²)        | O(n²)      |
| Selection Sort | O(n²)      | O(n²)        | O(n²)      |
| Merge Sort     | O(n log n) | O(n log n)   | O(n log n) |
| Stack Push     | O(1)       | O(1)         | O(1)       |
| Stack Pop      | O(1)       | O(1)         | O(1)       |
| Queue Enqueue  | O(1)       | O(1)         | O(1)       |
| Queue Dequeue  | O(1)       | O(1)         | O(1)       |

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/dsa-visualizer.git
```

2. Open the project folder.

```bash
cd dsa-visualizer
```

3. Open `index.html` in your browser.
